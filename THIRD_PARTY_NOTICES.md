# Attribution and licensing status

The paper bibliography cites the models, inventories, social-cognition tasks, and related methods used in the study. BFI-10 follows Rammstedt and John (2007); the LLM adaptation cites PsychoBench. Conformity prompts use an Asch-inspired paired-pressure design; wording probes cite CogMir as methodological inspiration.

The original project README attributes design influence or adaptation to HyperGraphRAG (graph memory and retrieval), FutureMap (reasoning/experience components), KnowledgeClaw (memory extraction), MiroFish (agent scaffolding), and OASIS (probe and trace patterns). That attribution is preserved here. The available workspace does not establish a complete upstream file-by-file license provenance record; authors should finalize it before offering a downstream reuse license.

Runtime dependencies are installed separately and retain their own licenses. This package distributes no LLM model weights. Model access and redistribution terms belong to their respective providers and model authors.

A project-wide LICENSE has not been supplied by the authors. Repository availability alone should not be interpreted as a grant to reuse the code or measurements under MIT, Apache, or another license. Add the authors' chosen license after confirming the rights in included assets.
